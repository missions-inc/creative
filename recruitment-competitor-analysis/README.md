# 採用競合・給与相場 分析ツール

クライアントの求人票を入力すると、**Indeed／ジョブメドレー／ハローワーク** の3媒体から
競合求人と給与相場データを自動調査し、クライアントにそのまま見せられる
**Excelレポート** を出力するツールです。

提案時・定例MTG前の「近隣競合のピックアップと給与相場比較」の情報収集を自動化します。

## できること

| ステップ | 内容 |
|---|---|
| ① 求人票の解析 | 職種・エリア・雇用形態・給与・PRポイント・福利厚生を自動抽出 |
| ② 競合求人の収集 | 同職種 × 同市内・同区内を中心に競合求人を約5件収集（3媒体限定） |
| ③ 給与相場の算出 | 同職種・近隣エリアの求人 約100件の給与を収集し、下限・中央値・上限を算出 |
| ④ 除外ルールの適用 | (1) 最低賃金を下回る求人 (2) 更新日が30日以上前の求人 を自動除外 |
| ⑤ Excelレポート出力 | サマリー／競合求人比較／給与相場データ の3シート構成 |

- 最低賃金は実行のたびに **Web検索で最新値を確認** し、取得できない場合のみ同梱の
  確定値テーブル（`app/min_wage.py`、厚生労働省 2024年度改定値）にフォールバックします。
- 相場統計（MIN／MEDIAN／MAX）や時給換算はExcel数式で組んであるため、
  レポート上でデータを修正すればその場で再計算されます。

## セットアップ

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."   # Anthropic APIキー
```

## 使い方

### CLI

```bash
python -m app --input samples/sample_job.txt --output 競合分析レポート.xlsx
```

`--input` にはクライアント求人票のテキストファイルを指定します
（求人票の本文をそのままコピー＆ペーストしたものでOK）。

### ブラウザUI（Streamlit）

```bash
streamlit run streamlit_app.py
```

求人票を貼り付けて「分析を実行」を押すと、完了後にExcelをダウンロードできます。

## 出力レポートの構成

| シート | 内容 |
|---|---|
| ① サマリー | クライアント求人概要／給与相場比較（相場ポジション判定つき）／分析条件・出典 |
| ② 競合求人比較 | クライアント行（ハイライト） vs 競合求人。給与・時給換算・PR・福利厚生・更新日・URL。除外した求人も理由つきで掲載 |
| ③ 給与相場データ | 収集した給与サンプル全件と、数式による相場統計（単位別に 下限／中央値／上限） |

**相場統計の定義**（レポート上にも明記されます）
- 相場下限 ＝ 各求人の下限給与の最小値
- 相場中央値 ＝ 各求人の代表値（下限と上限の中間）の中央値
- 相場上限 ＝ 各求人の上限給与の最大値

**換算の前提**
- 月給→時給: 月平均所定労働時間 173.8時間（週40h×52週÷12ヶ月）で換算。
  サマリーシートの青字セルを変更すると再計算されます。
- 日給→時給: 8時間/日で換算。

## 注意事項・運用メモ

- **実行時間**: 1回の分析でWeb検索を計30〜40回程度行うため、**5〜15分** かかります。
- **API費用**: Claude API（claude-opus-4-8）とWeb検索の従量課金が発生します。
  1回あたり数百円〜千円程度が目安です（検索件数・求人票の長さで変動）。
- **相場サンプル数**: 「約100件」は目標値です。エリアや職種によって収集できる件数は
  変動するため、実際の採用件数はレポートに明記されます。
- **更新日不明の求人**: 除外ルール②（30日）は更新日が判明した求人にのみ適用します。
  更新日が取得できなかった求人は「不明」と表示のうえ保持します（機械的に全除外すると
  ハローワーク等の求人が過剰に落ちるため）。
- **最低賃金テーブルの更新**: 毎年10月の改定後、`app/min_wage.py` の値を
  厚生労働省の「[地域別最低賃金の全国一覧](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/minimumichiran/)」で更新してください
  （更新しなくてもWeb検索での自動取得が優先されるため、フィルタが大きく狂うことはありません）。
- **利用規約**: 本ツールは検索エンジン経由の公開情報収集です。各媒体の利用規約の範囲で
  ご利用ください。取得した求人情報の出典URLはレポートに必ず記載されます。

## 開発者向け

```
app/
  __main__.py      # CLIエントリポイント（パイプライン全体の実行）
  parser.py        # ① 求人票の構造化解析
  research.py      # ②③ Web検索（競合収集・相場スイープ）
  filters.py       # ④ 除外ルール・最低賃金解決・統計
  report.py        # ⑤ Excelレポート生成
  claude_client.py # Claude API共通処理（web_search / 構造化抽出）
  schemas.py       # データモデル（pydantic）
  min_wage.py      # 地域別最低賃金フォールバックテーブル
  config.py        # 設定値（対象媒体・件数・換算前提など）
tests/
  build_mock_report.py  # API不要のレポート生成検証スクリプト
```

レポート生成部分だけを検証する場合（APIキー不要）:

```bash
python tests/build_mock_report.py mock_report.xlsx
```
